# Keybindings

[← README](../README.md)

Super + ? shows these on screen. Change them in `hypr/.config/hypr/keybinds.lua`. Terminal, browser,
file manager and editor open your [default apps](desktop.md#default-apps).

## Apps and system

| Keys | Action |
|---|---|
| Super + A | App launcher |
| Super + P | Projects |
| Super + V | Clipboard history |
| Super + T | Terminal with fastfetch |
| Super + Return | Terminal |
| Super + \` | Drop-down terminal |
| Super + B | Browser |
| Super + C | Text editor |
| Super + E | File manager |
| Super + N | Notifications |
| Super + Shift + N | Do Not Disturb |
| Super + S | Control center; Esc, arrows / Tab / J K and 1–9 work inside |
| Super + , | Settings app (appearance, fonts, bar, windows, effects, input); Ctrl+F searches |
| Super + Ctrl + W | Weather |
| Super + Shift + M | Music player (control center's Music tab) |
| Super + Shift + C | Color picker (copies hex) |
| Super + Shift + W | Wallpaper picker |
| Super + ? | Cheatsheet |
| Super + Escape | Power menu |
| Super + Alt + L | Lock |

## Windows

| Keys | Action |
|---|---|
| Alt + Tab | Switch windows |
| Super + Tab | Switch workspaces (hold Super, Tab to move, release to switch) |
| Super + Q | Close (Thunderbird and Chrome apps hide instead) |
| Super + F | Floating |
| Super + Ctrl + M | Maximize |
| Super + M | Fullscreen |
| Super + W | Group windows |
| Super + Arrows | Move focus |
| Super + Shift + Arrows | Move the window |
| Super + J | Change split direction |
| Super + - / = | Narrower / wider (Shift: shorter / taller) |
| Super + left / right drag | Move / resize |

## Workspaces and monitors

| Keys | Action |
|---|---|
| Super + 1…9 | Go to workspace |
| Super + Shift + 1…9 | Move the window there |
| Super + Alt + 1…9 | Move it there without following |
| Super + U / I or scroll | Next / previous workspace |
| Super + F1 / F2 | Scratch workspaces (Shift: move the window there) |
| Super + Ctrl + Arrows | Focus another monitor |
| Super + Shift + Ctrl + Arrows | Move the window to another monitor |
| Three-finger swipe | Switch workspace |

## Screenshots and recording

| Keys | Action |
|---|---|
| Print | Region → clipboard |
| Ctrl + Print | Screen → clipboard |
| Alt + Print | Window → clipboard |
| Super + Shift + F | Region → clipboard and `~/Pictures/Screenshots` |
| Super + Shift + R | Record a region (again to stop) |
| Super + Alt + R | Record the screen (again to stop) |

Recordings go to `~/Videos/Recordings`.
