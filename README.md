# dotfiles

Minimal Hyprland + Quickshell setup on CachyOS. Palette: Catppuccin Mocha.

Packages: hyprland quickshell hypridle hyprlock hyprpaper hyprpolkitagent fuzzel mako
kitty starship fastfetch cliphist wl-clipboard grim slurp jq brightnessctl stow
wf-recorder networkmanager-openvpn

Install:

    cd ~/dotfiles
    stow hypr quickshell fuzzel mako kitty starship fastfetch fontconfig

Keys: Super+Return terminal, Super+A launcher, Super+V clipboard, Super+Escape power menu,
Super+Alt+L lock, Print region screenshot (Super+Shift+F also saves it),
Super+Shift+R / Super+Alt+R record region / full screen (press again to stop).
Click the bar's vpn label to toggle the VPN (asks for the password once, then saves it).
